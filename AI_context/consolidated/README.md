# AI_context/consolidated

## Regra de promoção

Nenhuma issue vai para `consolidated` sem:

- critério de sucesso/falha **avaliado** (validado, refutado ou inconclusivo, com números)
- evidências linkadas
- ficha da estratégia e `docs/` atualizados, se o resultado os afeta

## Propósito

Transformar trabalho encerrado em conhecimento permanente, **inclusive hipóteses refutadas**. Saber que um sinal não funciona evita testá-lo de novo daqui a seis meses.

## Organização

- `history/`: issues encerradas, movidas de `../issues/` com `status: consolidated`. Guardam como se chegou ao resultado, o que foi decidido e o que ficou de fora.
- demais arquivos: documentos de conhecimento nomeados pelo assunto (ex.: `petr4-sinal-4-indicadores.md`), no formato de `templates/consolidated.template.md`.
